# Open Resume walkthrough

[Watch the video](open-resume-demo.mp4) · [Animated preview](../images/demo.gif)

A 30-second silent walkthrough, edited from real application captures. The
interface and sample resume are in English. All resume details are fictional;
the edited contact information uses an example domain and a fictional phone
number. The GIF is a shorter preview of the same screens.

| Time | What you see |
| --- | --- |
| 0–3 s | Open Resume: an open-source resume builder. |
| 3–7 s | Browse the gallery of 156 included templates. |
| 7–10 s | Preview the Purple Pro layout. |
| 10–16 s | Edit the sample profile and see the live preview update. |
| 16–21 s | Open style settings and change the accent color. |
| 21–25 s | Open the PDF, image, and JSON export menu. |
| 25–30 s | Self-host under MIT, or choose the paid hosted service at justcv.org. |

Captured from the local Docker build on 2026-10-20. The default `admin / admin`
login, saving and reloading the English document, changing its accent color,
and exporting an actual one-page A4 PDF were verified during capture.
